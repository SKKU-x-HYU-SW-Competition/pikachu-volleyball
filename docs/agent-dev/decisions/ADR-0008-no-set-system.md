# ADR-0008 — 세트제 도입 여부

| | |
|---|---|
| 상태 | RESOLVED |
| 결정일 | 2026-07-07 |
| 결정자 | Claude Code (사용자 승인) |
| 반영 | [CONTRACTS.md](../CONTRACTS.md) §1.2 (`meta`에서 `set`/`max_set` 제외) |

## 배경 (왜 막혔는지)

브레인스토밍 초안에 `meta.set`/`max_set` 필드가 있었는데, 실제 엔진(`pikavolley.js`)은 단판
(`winningScore=15`)까지만 지원하고 다세트 구조가 없음. 세트제를 넣으려면 컨트롤러 레벨 로직을 새로
만들어야 함.

## 결정

**도입하지 않는다.** 다판 대결이 필요하면 엔진 안에 세트 개념을 넣지 않고, 운영 스크립트 레벨에서
그냥 여러 판을 실행하는 방식으로 처리. 프로토콜/엔진에 부담을 얹지 않음.
