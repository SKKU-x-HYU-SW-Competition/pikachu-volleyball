# ADR-0005 — 팀 로스터 / 트랙 오너십

| | |
|---|---|
| 상태 | RESOLVED (부분) |
| 결정일 | 2026-07-10 |
| 결정자 | 팀장(사용자) |
| 반영 | [AGENTS.md](../../../AGENTS.md) §4 담당자 표 |

## 배경 (왜 막혔는지)

[AGENTS.md](../../../AGENTS.md) §4의 담당자 표가 비어 있음. 누가 어느 트랙을 맡고 누가 리뷰하는지,
각자 어떤 에이전트 도구를 쓰는지 안 채워져 있었음.

## 결정

**현재 이 스레드/세션에서 진행되는 작업 기준으로는 팀장(마스터, 사용자)과 Claude Code로 채운다.**
아직 이건 전체 팀 로스터(다른 공동 운영진이 참여하고 각자 다른 도구를 쓰는 구조 — AGENTS.md §4 원래
취지)를 확정한 게 아니라, 지금 당장 진행 중인 작업의 담당을 명시한 것. 다른 공동 운영진이 합류하면
트랙별로 담당/리뷰/도구를 다시 채워야 함 — 그때 이 ADR을 갱신하거나 새 ADR로 등재.
