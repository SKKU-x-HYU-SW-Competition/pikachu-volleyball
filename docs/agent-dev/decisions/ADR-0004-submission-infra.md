# ADR-0004 — 제출 인프라

| | |
|---|---|
| 상태 | RESOLVED |
| 결정일 | 2026-07-10 |
| 결정자 | 팀장(사용자 승인) |
| 반영 | Phase 3 설계 시 기본 전제로 사용 (아직 CONTRACTS.md에 반영할 프로토콜 필드는 없음) |

## 배경 (왜 막혔는지)

별도 제출 플랫폼을 만들지, 이메일로 파일을 받아 운영진이 수동으로 넣어줄지 미정.

## 결정

**임시로 "이메일 제출 + 운영진 수동 로드"를 가정하고 설계/개발을 진행한다.** 별도 제출 플랫폼(웹
업로드 폼 등)을 지금 만들지 않고, Phase 3(제출/중계)는 이 가정을 전제로 설계. 더 나은 인프라 필요성이
실제로 확인되면(예: 참가자 수가 많아 수동 로드가 병목이 되는 경우) 그때 재논의하고 이 항목을 갱신.
