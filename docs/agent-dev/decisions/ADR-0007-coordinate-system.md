# ADR-0007 — 좌표 변환 방식

| | |
|---|---|
| 상태 | RESOLVED |
| 결정일 | 2026-07-07 |
| 결정자 | Claude Code (사용자 승인) |
| 반영 | [CONTRACTS.md](../CONTRACTS.md) §1.2 (좌표계/상수 표) |

## 배경 (왜 막혔는지)

원본 엔진은 y가 아래로 증가하는 스크린 좌표계(바닥이 `y=244`/`252`, `y=0`이 화면 최상단)를 쓰는데,
이걸 "바닥=0, 위로 증가"하는 직관적 좌표로 변환해서 줄지, 원본 그대로 줄지 미정이었음.

## 결정

**변환 없이 원본 정수 픽셀 좌표를 그대로 노출한다.** 물리 엔진이 전부 정수 픽셀 + `| 0` 절삭
연산으로 되어 있어서, 임의로 스케일/축을 바꾸면 봇이 궤적을 정밀 예측하려 할 때 오차 요인만 늘어남.
원본 코드와 1:1로 대응시키는 편이 구현 리스크도 낮음.
