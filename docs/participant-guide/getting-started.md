# 환경 세팅 · 실행

봇을 짜서 로컬에서 붙여보는 데까지 필요한 작업을 처음부터 순서대로
정리했습니다. 처음 세팅은 10분 정도, 두 번째부터는 `npm start` 한 줄로 끝납니다.

## 0. 사전 준비물

미리 설치되어 있어야 하는 것들:

- **Node.js LTS 버전** — [nodejs.org](https://nodejs.org/)에서 설치.
  터미널에서 `node --version`을 쳤을 때 버전이 뜨면 OK.
- **Git** — Mac은 대개 이미 있고, Windows는
  [git-scm.com](https://git-scm.com/)에서 설치.
- **Chrome (권장)** — 다른 최신 브라우저(Edge, Firefox, Safari)도
  대체로 되지만, 대회 환경 기준은 Chrome입니다. 문제 재현/디버깅도
  Chrome에서 하는 게 편합니다.

Python 봇을 짜더라도 **로컬에 Python을 설치할 필요는 없습니다** —
브라우저 안에서 Pyodide로 실행되기 때문입니다.

## 1. 저장소 받기

먼저 터미널(명령어 창)을 엽니다. OS별로 방법이 다릅니다:

- **macOS**: Spotlight(⌘ + Space)에서 "터미널"을 검색해서 실행.
- **Windows**: 시작 메뉴에서 **PowerShell** 또는 **Windows Terminal**을
  검색해서 실행. (`cmd`도 되지만 PowerShell을 권장)
- **Linux**: 평소에 쓰던 터미널 그대로.

원하는 폴더로 이동한 뒤, 아래 명령을 순서대로 입력합니다:

```bash
git clone https://github.com/SKKU-x-HYU-SW-Competition/pikachu-volleyball.git
cd pikachu-volleyball
npm install
```

- 첫 줄: 저장소를 현재 폴더 아래로 내려받습니다.
- 두 번째 줄: 내려받은 프로젝트 폴더로 들어갑니다. **이후 모든 명령은
  이 폴더 안에서 실행합니다.**
- 세 번째 줄: 필요한 라이브러리를 설치합니다. 인터넷 속도에 따라
  1~3분 정도 걸릴 수 있습니다.

`npm install`은 **처음 한 번만** 하면 됩니다. 다음부터는 바로 3단계(게임
실행)로 갈 수 있습니다.

## 2. 봇 파일 넣기

> **키보드로만 플레이할 계획이면 이 단계는 건너뛰어도 됩니다.** 나중에 봇
> 코드를 붙일 때 다시 돌아와서 진행하세요.

`src/code-here/` 폴더에 파일 하나만 만들면 됩니다.

```
src/code-here/
├── Example_v1.js      ← 처음부터 들어있는 예제 (JS)
├── Example_v1.py      ← 처음부터 들어있는 예제 (Python)
└── MyTeam_v1.js       ← 여러분이 새로 만든 파일
```

### 파일명 규칙

```
<팀명>_v<버전>.<js|py>
```

- 마지막 `_v` 앞이 팀명, 뒤가 버전으로 파싱됩니다. 팀명 안에 `_`가 들어가도 괜찮습니다 (`Team_A_v1.js` → 팀 `Team_A`, 버전 `1`)
- 확장자로 언어를 자동 판별합니다 — `.js`면 JavaScript, `.py`면 Python
- 버전은 문자열이라 `1`, `1.2`, `20260814` 등 자유롭게

**동일한 팀명 + 버전 + 언어면 UI 드롭다운에 하나로만 보입니다.** 대회 당일 코드
수정 후 재제출할 땐 버전 번호를 올려서 이전 버전과 구분하는 걸 권장합니다.

### 파일 내용의 최소 형태

**JavaScript**:
```js
function decide(snapshot) {
  return { x: 0, y: 0, hit: 0 };
}
```

**Python**:
```python
def decide(snapshot):
    return {'x': 0, 'y': 0, 'hit': 0}
```

파일 최상위에 `decide`라는 이름의 함수가 있으면 됩니다. 다른 헬퍼 함수·상수는
`decide` 위에 자유롭게 정의해도 되고, 파일 최상위에 있는 변수는 매 틱 사이에
그 값이 유지됩니다 (자세한 건 [API 페이지](api.md)의 "봇 실행 모델" 참고).

## 3. 게임 실행 (dev 서버 띄우기)

터미널에서 **저장소 폴더 안에서** 아래 명령을 입력합니다:

```bash
npm start
```

명령을 실행하면 잠시 뒤 다음과 비슷한 로그가 뜨고 그대로 서버가 열려
있습니다:

```
<i> [webpack-dev-server] Project is running at:
<i> [webpack-dev-server] Loopback: http://localhost:8080/
```

**이 터미널 창은 켜둔 채로** 두세요. 창을 닫거나 `Ctrl + C`를 누르면
게임이 꺼집니다.

## 4. 브라우저로 접속하기

Chrome을 열고 주소창에 다음을 입력해서 접속합니다:

```
http://localhost:8080
```

로딩이 끝나면 소개 박스와 함께 피카츄 배구 게임 화면이 뜹니다.

> `src/code-here/`에 파일을 추가하거나 수정하면 dev 서버가 자동으로
> 재빌드해서 브라우저에 반영됩니다. 서버를 재시작할 필요는 없습니다.
> (변경이 안 보이면 브라우저에서 새로고침 한 번만 해주세요.)

## 5. 게임 화면에서 "게임 시작" 누르기

브라우저에 로드되면 처음엔 게임 소개 박스가 떠 있습니다.
**오른쪽 위의 "게임 시작"** 버튼을 눌러 게임 화면으로 진입하세요.

## 6. 봇 설정 창으로 붙이기

게임 화면 상단 메뉴바의 **"봇 설정"** 버튼을 누르면 패널이 열립니다.

```
┌─────────────────────────────────────────┐
│ LEFT               RIGHT                │
│ ○ Keyboard         ● Keyboard           │
│ ● Bot              ○ Bot                │
│ ○ AI               ○ AI                 │
│ [ MyTeam v1 (JS) ▼ ]  [ -- 봇 선택 -- ▼ ] │
│ 상태: 봇 코드 로드됨   상태:              │
│                                         │
│          [ 적용(재시작) ]                │
└─────────────────────────────────────────┘
```

각 side(왼쪽/오른쪽)마다 **세 가지 모드**를 고를 수 있습니다:

- **Keyboard**: 사람이 키보드로 조작 (원작 그대로)
- **Bot**: 여러분이 짠 봇 코드. 아래 드롭다운에서 `src/code-here/`에
  넣어둔 파일 하나를 선택합니다. 드롭다운에 파일이 안 보이면
  파일명 규약(`<팀명>_v<버전>.js|py`)을 다시 확인해주세요.
- **AI**: 원작에 내장된 컴퓨터 AI

양쪽 모두 선택한 뒤 **"적용(재시작)"** 버튼을 누르면 그 설정으로
매치가 시작됩니다. (이때 게임이 초기화되면서 재시작됩니다.)

**요약 흐름**: 게임 시작 → 봇 설정 → 왼쪽·오른쪽 모드 선택 →
(봇이면) 파일 선택 → 적용 (재시작).
