# 대회 규칙

> 이 페이지는 **봇 코드에 관한 기술 규칙**만 다룹니다. 대회 진행(대진표,
> 시간표, 상금 등)은 별도 안내를 참고하세요.

## 제출 형식

- **파일 하나**로 제출합니다. 여러 파일로 나눠 `import`할 수 없습니다.
- **파일명**: `<팀명>_v<버전>.<js|py>`
  - 예: `Alpha_v1.js`, `Beta_v2.py`, `Team_A_v20260814.js`
  - 팀명에 언더스코어 가능. **마지막 `_v`**를 기준으로 팀명·버전이 갈립니다
  - 팀명·버전에 공백·특수문자(따옴표·경로 구분자 등)는 넣지 마세요
- **언어**는 확장자로 결정: `.js` = JavaScript, `.py` = Python. 별도 지정 없음
- 같은 대회에 **한 팀이 여러 버전**을 등록할 수 있습니다 (`Team_v1.js`,
  `Team_v2.js`). 파일별로 하나의 봇으로 취급됩니다.

## 봇 코드가 지켜야 할 것

### 필수

1. 최상위에 `decide` 함수가 정의되어 있어야 함
2. `decide(snapshot)`는 `{x, y, hit}` **dict/object**를 반환
   - `x ∈ {-1, 0, 1}`, `y ∈ {-1, 0, 1}`, `hit ∈ {0, 1}`
   - 잘못된 값은 해당 tick만 무입력 처리 (매치는 계속 진행)

### 시간 예산

- **결정 목표: tick 주기 120ms 안에 리턴** (`decide`가 3프레임 × 40ms마다 한 번 호출됨)
  - 넘기면 그 결과는 다음 다음 tick에나 반영되어 반응이 늦어집니다
- **Hard timeout: 360ms** (`= 40ms × 3 × 3`). 이걸 넘긴 응답은 폐기되고 그 tick은 무입력 처리
- **15 tick 연속** hard timeout이면 봇 워커 강제 재시작 (파일 재로드 → 전역 상태 초기화)
- 초기화(파일 로드 시점) 제한: **60초** 이내 준비 완료. Python + numpy 로딩이
  이 안에 반드시 끝나야 함 (평상시 5~10초)

### 언어별 사용 가능 범위

**JavaScript**
- 사용 가능: 표준 JS 전역 (`Math`, `Date`, `JSON`, `console.log`, `Array`, `Map`, `Set`, `RegExp` 등)
- 사용 불가: `import`/`require` (파일 격리됨), `fetch`/XHR, DOM (`window`, `document`), Worker 생성

**Python** (Pyodide 위)
- 사용 가능: Python 3 표준 라이브러리 전체, **numpy** (`import numpy as np`)
- 사용 불가: `scipy`, `pandas`, `scikit-learn`, `torch` 등 서드파티 / 파일 I/O /
  네트워크 / `subprocess`
- `import` 실패 시 초기화 에러로 처리됨 (매치 못 나감)

### 실행 환경 제약

- 봇은 각자 **Web Worker 안에서 격리**되어 실행됩니다. 게임 메인 스레드나
  상대방 봇을 방해할 수 없습니다.
- 무한루프를 돌려도 상대는 정상 진행하고, 여러분 봇만 계속 무입력이 나오다가
  결국 강제 재시작됩니다 (사실상 실격 수준의 패널티).

## 매치 규칙 (게임 자체)

원작 [피카츄 배구](https://github.com/gorisanson/pikachu-volleyball)의 룰을
**기본적으로** 따릅니다. 그 외에 대회를 위해 정해진 사항은 다음과 같습니다.

- **10점 선착제** — 세트 수(단판/3판2선승 등)는 **차후 결정 예정**
- **서브권은 매치 시작 시 랜덤**으로 결정됩니다 (원작처럼 고정된 규칙이 아님)
- **한 진영에서 연속 5회 접촉 시 실점** — 원작에는 없는 규칙입니다. 공이
  네트를 넘지 않은 채 같은 편에서 5번째로 공에 닿는 순간 상대에게 점수가
  넘어갑니다 (자기 자신에게 계속 토스하며 랠리를 무한히 끄는 것을 막기 위함)
- 게임 프레임 25 FPS (1프레임 = 40ms), 봇 결정 주기는 3프레임(120ms)
- 특별한 스킬은 대회 당일 별도 공지 (해당 시 이 문서와 API 문서를 갱신합니다)

## 부정행위로 간주되는 것

- 파일 최상위 실행 시점에 매치와 무관한 대량 연산을 돌려 초기화 타임아웃을
  일부러 넘겨 상대 시스템을 방해하려는 시도
- 브라우저 취약점·엔진 버그 exploit (예: 물리 엔진의 특정 값에 NaN/Infinity를
  주입해 판정을 흐트리는 시도)
- 게임 코드·상대 봇 코드를 훔치거나 수정하려는 시도

**의도치 않은 버그**는 부정행위가 아닙니다. 위 항목들은 "고의로" 그런 짓을
할 때에 해당합니다. 헷갈리면 운영진에 문의하세요.
