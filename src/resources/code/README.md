# Sample bots

참가자 관점 테스트를 위한 단일 파일 봇 예제입니다. 각 파일은 Bot Setup의 코드 입력란에 그대로
붙여넣을 수 있으며, 같은 번호의 JavaScript/Python 파일은 같은 판단 순서와 임계값을 사용합니다.

| 번호 | 봇 | 추가되는 개념 | 의도적인 한계 |
|---|---|---|---|
| 01 | Basic chaser | 스냅샷 읽기, 좌우 이동, 코트 경계 | 점프·공격·자기 코트 판정 없음 |
| 02 | Defender | 대기 위치, 예상 착지점, 조건부 점프 | `hit`을 사용하지 않음 |
| 03 | Attacker | 공중 추적, 파워히트, 거리별 타구 각도 | 다이빙·상대 분석 없음 |
| 04 | Adaptive | 행동 모드, 다이빙, 상대·점수·이전 틱 활용 | 규칙 기반 임계값이라 빠른 반사에 취약 |

## 사용법

1. 게임의 Bot Setup에서 사용할 진영을 `Bot code`로 선택합니다.
2. 파일 확장자에 맞춰 JavaScript 또는 Python을 선택합니다.
3. 파일 전체를 코드 입력란에 붙여넣고 `Apply (restart)`를 누릅니다.
4. 인트로와 메뉴를 통과해 새 라운드를 시작합니다.

봇 진입점은 JavaScript의 `function decide(snapshot)` 또는 Python의 `def decide(snapshot)`이며,
항상 `x: -1|0|1`, `y: -1|0|1`, `hit: 0|1`을 반환해야 합니다. 전체 스냅샷과 실패 처리 규칙은
`docs/agent-dev/CONTRACTS.md`를 기준으로 합니다.

## 검증 관점

- 모든 파일을 LEFT와 RIGHT 양쪽에서 실행합니다.
- 01은 이동, 02는 이동과 점프, 03은 `state 0 -> 1 -> 2`, 04는 점프·타격·다이빙·회복을 확인합니다.
- 같은 번호의 JS/Python 봇에는 같은 대표 스냅샷을 입력하고 반환 액션이 같은지 비교합니다.
- 이 파일들은 전략 실험용입니다. 참가자에게 최종 공개할 봇은 실제 대전 후 별도로 선별합니다.
